Actualizaciones del complemento

Correo Calendario 0.7.1

Thunderbird administra las actualizaciones cuando la página de publicación está disponible.

En Thunderbird abre Complementos y temas → engranaje → Buscar actualizaciones. Activa «Actualizar complementos automáticamente». Para comprobar una versión nueva, utiliza el gestor nativo de complementos de Thunderbird.

La instalación conserva el ID del complemento y los datos del perfil. Haz respaldo antes de una versión mayor.

Privacidad y continuidad

El complemento utiliza las cuentas SMTP configuradas en Thunderbird. No pide ni almacena sus contraseñas.

Los datos de personal y las imágenes se guardan en el perfil local. No están cifrados por el complemento; aplica las políticas de seguridad del equipo y realiza respaldos del perfil.

Para los envíos programados: Thunderbird debe permanecer abierto y la PC activa. Si se apaga, los mensajes pendientes se revisan al volver a abrir Thunderbird.

Calendario Thunderbird: la exportación .ics requiere importación manual. No hay sincronización bidireccional sin una API experimental con permisos completos.

Fotos: se incluyen como adjunto de respaldo; confirma en el mensaje recibido si Thunderbird las integró en el HTML.
