# Preauditoría conforme a Thunderbird Add-ons (ATN)

Fuente: https://thunderbird.github.io/atn-review-policy/

**Comprobación estática local:** manifest, ID, versión mínima, sintaxis, prueba simulada de listas CCO y vCard, verificación de hash XPI y exclusión de fuentes de prueba del paquete.

**Riesgos a revisar por Mozilla:** acceso a contactos (probable revisión manual), permisos sensibles, manejo de fotografías personales, sanitización HTML, política de privacidad, explicaciones para el revisor y fiabilidad en Thunderbird real.

**Pendiente:** envío formal a addons.thunderbird.net, validación automática oficial, revisión humana y firma cuando sea aplicable. No se realizó ni puede afirmarse una revisión por IA de Mozilla. El informe local no equivale a aprobación.
