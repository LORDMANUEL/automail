# AutoMail: origen y visión

AutoMail nació de una necesidad real: automatizar felicitaciones y comunicaciones desde Thunderbird, reutilizar las libretas existentes y evitar crear fichas duplicadas. Durante las pruebas se corrigieron problemas de envío, listas CCO, fechas, plantillas HTML, fotos y duplicaciones.

**Visión:** un complemento ligero, local y universal que convierta Thunderbird en una herramienta confiable para programar correos sin servidor de envíos adicional.

**Objetivos:** claridad de destinatarios Para/CC/CCO; programación por fecha; fotos y plantillas reutilizables; contactos nativos; mensajes privados; historial; actualizaciones HTTPS.

**Usuarios:** cualquier persona, con usos destacados en Recursos Humanos, Servicio de Atención al Cliente, comunicaciones, ventas y educación. RRHH no es un módulo obligatorio.

Thunderbird debe permanecer abierto y el PC encendido para despachar mensajes programados.
