# PRD V0.7.0

## Requisitos
1. Elegir contactos y listas de la agenda nativa; permitir búsqueda y selección múltiple.
2. Enviar un solo comunicado a N personas en CCO sin mostrar la lista en la bandeja del destinatario.
3. Felicitar a un contacto en Para y copiar a una lista en CC o CCO mediante un solo envío.
4. Usar HTML y CSS compatible con correo, fotos y campos {{nombre}}, {{mensaje}}, {{puesto}}, {{foto}}, {{empresa}}, {{sucursal}}.
5. Editar nombre, puesto y fotografía de un contacto por ID, sin modificar otros campos vCard.
6. Programar y cancelar; mostrar estados de envío, incidentes y notificaciones.
7. Actualizar desde un manifiesto JSON vía HTTPS.

## Indicadores deseados
Tres pasos para programar; cien por ciento de envíos con resumen de direcciones previo; cero reenvíos automáticos ante estado incierto.

## Fuera del alcance
PC apagada, Thunderbird cerrado, sincronización nativa bidireccional con calendario sin API especializada y certificación de entrega SMTP final.
