# Privacidad AutoMail

Los contactos, listas, nombres, puestos, fechas, fotografías, identidades y mensajes se procesan para preparar las comunicaciones que configura el usuario. La agenda y programaciones permanecen en su perfil local de Thunderbird; la extensión no incorpora un servicio remoto ni telemetría propia.

Al enviar, el contenido y destinatarios se entregan al servidor SMTP que el usuario ya configuró en Thunderbird. Las búsquedas de actualización solicitan archivos públicos por HTTPS a GitHub Pages, que puede conservar registros técnicos.

El usuario puede editar sus contactos en Thunderbird, cancelar trabajos y administrar fotografías. Las fotos y fechas de otras personas deben utilizarse con la autorización correspondiente. AutoMail no cifra de manera independiente todo el perfil Thunderbird. No solicita ni transmite credenciales SMTP a GitHub.
